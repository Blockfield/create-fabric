# Blockfield/create-fabric bf3

## Кратко

Точечный релиз: изогнутые и наклонные рельсы Create получили твёрдые столкновения вместо прохождения игрока/сущностей насквозь, при этом просвет для передвижения ползком (crawl) сохранён. Второй коммит — только документация репозитория, на игру не влияет.

## Для игроков

Исправление: игрок и сущности больше не проваливаются сквозь изогнутые и наклонные рельсы — у них появилась твёрдая коллизия, как у прямых. Просвет, нужный для передвижения ползком под путями, не пострадал.
Остальных игровых изменений в промежутке нет — второй коммит добавляет только пояснение в README о том, как форк попадает в сборку Blockfield.

## Технические изменения

`FakeTrackBlock`/`FakeTrackBlockEntity` и `TrackBlock`/`TrackBlockEntity` дополнены расчётом коллизии (новые `TrackCollision`, `TrackCollisionCheck`) для кривых и наклонных секций рельс; `AllBlocks` избавлен от одной неиспользуемой записи. Правки затрагивают только клиент/сервер мода Create, сборку не меняют.

## Обновлённые компоненты

Изменений версий зависимостей в этом промежутке нет — правка внутри самого форка (добавлена коллизия рельсов), апстрим Create и Porting Lib не тронуты.

## Совместимость и необходимые действия

Правка коллизии затрагивает и клиент, и сервер (общий код блока/entity рельсов) — пин пака нужно обновить одновременно на обеих сторонах.

## Известные проблемы

Сведений нет — в коммитах промежутка не упоминаются открытые проблемы.
