# Blockfield/create-fabric bf2

## Кратко

Первый релиз форка Create для Blockfield: сборка мода на Fabric 1.21.1 вместо исходного NeoForge, через Porting Lib. По коммитам промежутка это доводка порта до рабочего состояния — компиляция, датаген под Fabric, замена совместимостей — плюс несколько точечных исправлений и один игровой возврат функциональности.

## Для игроков

Новое: вернулись нативные широкие рельсы (wide gauge) и рельсы с кривыми Безье, убранные при портировании. Уменьшенные эффекты разрушения блоков теперь управляются тегом. Крепление к цепному конвейеру учитывает атрибут масштаба игрока (было проигнорировано, #7610).
Исправления: рецепты с результатом в виде ItemStack (совместимость с Yuushya), исправлены крепления и текстуры при подключении к передвижным хранилищам, тултип количества жидкости в JEI показывает реальный объём, а не вместимость слота, поправлена интеракция и несколько крашей, возникших при портировании.
Изменения поведения: рецепты и теги перегенерированы под Fabric (в частности, `c:ingots/*` переведены на v2-имена) — сторонние моды и датапаки, ссылавшиеся на старые теги, надо будет обновить.
Остальное в промежутке — внутренняя работа над портом (см. «Технические изменения»), без видимых для игрока эффектов.

## Технические изменения

Перенос Create 6 c NeoForge на Fabric 1.21.1 поверх Porting Lib beta.90 (пакеты blocks/items/entity injects/resources, Registrate без транзитивного common). Датаген переведён на Registrate-Fabric: лут-провайдер отключён, ArchEx-совместимость снята, конфликт-маркеры в data убраны. `Container`/`RecipeInput` разведены отдельным ремапом (`LegacyRecipeWrapper`, `ProcessingInventory.asRecipeInput`). Меню и transfer API переведены на события Porting Lib 3.1 с кодеками. Совместимость с EMI/REI/FTB/CC для Fabric-сборки не перенесена (снята вместе с их подключением). Рантайм-зависимости: Ponder 1.0.69, Flywheel 1.0.6, Milk Lib 1.21.1 (Modrinth), рендер жидкостей — через Catnip. `HumanoidArmorLayerMixin` и `GuiMixin` переведены на ванильные сигнатуры 1.21.1 (без NeoForge-хука FFFFFF), временный `NullJsonDebugMixin` убран, гейм-тестовые миксины сняты. CI: публикация jar на тегах `bfN`, сборка ограничена 30 минутами на Java 21.

## Обновлённые компоненты

- Porting Lib: зафиксирован на 3.1.0-beta.90 (используется для событий, инжектов блоков/предметов/сущностей и ресурсов).
- Ponder: 1.0.69.
- Flywheel: 1.0.6.
- Milk Lib: 1.21.1 (подключена с Modrinth).
- Совместимость с EMI/REI/FTB/CC (апстрим Create) в этой сборке не включена.
Версия самого Create до/после в коммитах не указана — это перенос уже актуальной на момент порта кодовой базы на новую платформу (Fabric 1.21.1), а не апгрейд с прежней версии мода.

## Совместимость и необходимые действия

Мод действует на обеих сторонах: коммиты меняют и серверные данные (рецепты, теги, датаген), и клиентский рендер (миксины GUI и брони). Пин в паке нужно обновлять одновременно на клиенте и на сервере. Датапаки/моды со ссылками на теги `c:ingots/*` в старом (v1) формате нужно обновить под новые имена.

## Известные проблемы

В коммитах промежутка есть отметка о временно неудачной компиляции при переходе на Porting Lib beta.90, но следующие же коммиты доводят порт до рабочего состояния («Порт Create 6 на Fabric 1.21.1 компилируется»). Открытых проблем на момент тега bf2 в коммитах не зафиксировано. Сведений о проблемах, не отражённых в коммитах, нет.
